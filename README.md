# 維新の乱流 ― 幕末、日本の夜明けを設計せよ ―

<img src="assets/hero-bakumatsu.webp" alt="幕末の城下と黒船を望み、それぞれの未来を見据える人々" width="760">

幕末を舞台にした歴史設計シミュレーション。戦争も領地経営もない。
**人物の欲望・立場・論理を読み、ときに刃をかわしながら、言葉で歴史を動かす。**

主人公は、幕府にも朝廷にも藩にも属さない**無名の周旋家**。
開始時に**出自**を選ぶ（郷士の子／廻船問屋の手代／村方の名主の子）。誰があなたに会いに来るか、
相手があなたの身分をどう見るか、こちらがどう名乗るかが変わる。
そこから先は行動しだいで、どこかの急先鋒になるか、二勢力をつなぐ仲介人になるか、敵だけを作って消えるかが変わる。

原案は AI をゲームマスターとして動かすプロンプト
（[ミッキーベルグ氏 / note](https://note.com/mickey_bergdol/n/n1c29ef153438)）。
本リポジトリはそのルールを **LLM を使わない決定論的プログラム**として再実装したもの。

## 遊ぶ

**[ブラウザで遊ぶ](https://shigetane2011-cell.github.io/isin/)**

ローカルでは `index.html` をブラウザで開くだけ。ビルド不要、依存なし、通信なし。
画像はすべて同梱され、タイトル・面会中の勢力・到達したエンディングの分だけ読み込む。
初回だけ、正解と人物の返答に基づく根拠を見ながら第1ターンを進めるガイドを任意で選べる。
タイトルの seed は毎回ランダムに用意され、表示後はその値で固定・再現される。

## 30秒でわかる遊び方

1. **どこへ行き、誰に会うか**を同じ画面で決める — 行き先で面会候補が替わり、遠路の直行では候補が1名減る
2. 相手を**調べる** — **観る**（その項目の所作が読める）と**訊く**（その項目が二択になる）を**一度ずつ**。
   問うと、その項目の不正解が1枚消えて**三択が二択になる**。正解そのものは人物描写から読む。
   足りなければ一局に一度の奥の手で**さらに聞き出せる**（獲得−1）
3. **支持する**か、**論破して転向させる**かを決める
4. **どう働きかけるか**を選ぶ — 論じる／酌み交わす／金品を贈る／肚を割る
5. **論証カード**を組む — 枚数は働きかけで変わる（3枚／2枚／0枚／1枚）
6. **相手の反応を見る** — 身振りと本人の一言で、何がどこまで届いたかを受け取る

### あなたの立場

新しい能力値はない。現在の時勢、人脈、交わした約束、決裂した相手から、周囲があなたを
どう見ているかを毎ターン算出する。交渉と幕間の結果には、行動前から行動後への変化が出る。

> どこにも属さない無名の周旋家 → 開国寄りと見られ始めた周旋家<br>
> 開国と雄藩をつなぐ仲介人 → 開国通商の旗頭

エンディングでは国の行方だけでなく、最終的な呼ばれ方、人脈、約束、敵、そして自身の末路が語られる。

### 相手の反応

交渉の結果では、得点の説明より先に相手自身が反応する。人物絵がある主要人物はその肖像、
それ以外は所属勢力の情景を、勢力色の枠と座布団に載せる。

反応は **拒絶／一言だけ残る／警戒がほどける／心を決める** の四段階。
同じ判定でも、論じた相手は論の筋へ、杯を交わした相手は席の空気へ、金品を贈った相手は包みへ、
肚を割った相手はこちらの旗色へ反応する。支持と転向、立ち合い、再訪からの和解も別の言葉になる。
語り口は人物の身分に合わせた4系統で、肖像を持つ主要人物8名は心を決めた時と拒絶に固有台詞を持つ。
これは判定後の派生表示であり、得点・状態・保存コードには影響しない。

| 働きかけ | 決定の形 | 上限 | 特徴 |
|:---|:---|:---|:---|
| 論じる | カード3枚 | 大成功 | 最も高く積めるが、読みが要る |
| 酌み交わす | カード2枚（利益・文脈） | 成功 | **杯を交わした相手は刃を抜かない** |
| 金品を贈る | カードなし | 成功 | 確実。一度きりの奥の手を使う。**大義に生きる者には侮辱** |
| 肚を割る | カード1枚（利益） | 大成功 | 当たれば大きい。外せば決裂＋旗色ごと恥をかく |

### 行き先

| 場 | 集まる者 | 使える働きかけ | 深く刺さる |
|:---|:---|:---|:---|
| 祇園の茶屋 | 公武・抗戦 | 論じる・酌み交わす・肚を割る | 酌み交わす |
| 江戸城中 | 佐幕・公武（中級期から） | **論じるのみ** | 論じる |
| 長崎の商館 | 開国 | 論じる・金品・肚を割る | 金品を贈る |
| 藩邸の書院 | 雄藩・佐幕 | 論じる・肚を割る | 肚を割る |
| 壬生の屯所 | 佐幕・抗戦（荒事） | 論じる・酌み交わす・肚を割る | 肚を割る |
| 夜の街道 | 抗戦・雄藩（荒事） | 論じる・酌み交わす・肚を割る | 酌み交わす |

**同じ場に続けては行けない。** 毎晩同じ茶屋に通えば噂になる。

**京・江戸・長崎の異なる都市圏を一息に移ると旅疲れになり、その日の通常候補は3名から2名に減る。**
得点や別の体力ゲージは減らない。夜の街道は移動の中継地で、そこでも普段どおり面会できる。
都市→街道→都市と一晩ずつ進めば候補は減らず、急いで直行するか、道中の出会いを拾うかを選べる。

**響く当たり方は、その者が何を欲しているかで決まる。**

| その人物が欲しているもの | 響く当たり方 |
|:---|:---|
| 大義・理念／知・学問 | 論じる |
| 安全・保身 | 酌み交わす |
| 金銭・利権 | 金品を贈る |
| 名誉・武名／力・武備 | 肚を割る |

欲しているものは、面会中に**一つだけ問うと不正解を一つ除外できる**ほか、【情勢】の描写からも読める。
一局に一度だけ「さらに聞き出す」と、三つすべてが分かる。
この表はゲーム中、働きかけを選ぶ画面にも常に出る。

**同じ論でも、誰に向かって言うかで札の文面が変わる。**
相手は〔上：朝廷・幕閣・大名〕〔中：藩士・志士・学者〕〔下と外：町人・女・異人〕に分かれ、
札はその3通りで書き分けてある（勢力5 × カテゴリ3 × 動機6 × 立場3 = **270枚**）。

| 〔開国〕×〔金銭・利権〕を | 札の文面 |
|:---|:---|
| 大名・幕閣に | 運上金は御公儀の金蔵をそのまま潤しまする。何年ぶんにもなりましょう |
| 藩士・志士に | たった一度の交易で、藩の借財など塵芥にございます |
| 町人・異人に | 一度の船荷で、蔵がひとつ建ちまする。それが交易にございます |

**切り出し方も、相手と盤面で変わる。** 公家には「畏れながら申し上げる」、
町人には「商いの話としてお聞きください」。一度決裂した相手には
「前のことは詫びる。その上で申す」から入る。

**相手の返答も身分ごとに違う。** 語り口は7つ（志士・武家・公家・町人・女・学者・異人）で、
通常の否定返答と、奥の手・チュートリアルで明かす返答は、それぞれ
3カテゴリ × 6動機 × 7語り口 = **126通り**。

**論証カードには、その札が訴えかける先が書いてある。**

```
〔知・学問〕有職故実に通じた者こそ、次の世の礎となりましょう
〔大義・理念〕万世一系の御稜威を仰ぐ。それ以上の大義がありましょうか
〔名誉・武名〕この一挙、朝廷の記録に貴殿の名が残りましょう
```

問われているのは「どの文がどの動機か」ではなく、**この人物が何を欲しているか**である。

**ただし29名は表から外れる。**「豪商だが金では動かぬ」「力自慢だが酒で落ちる」の類いで、
手掛かりは【情勢】の描写のほうにある。

**金品を贈る／肚を割るは、相手を読み切った前提の賭け**なので、外すと逆に一段下がる。
論じる／酌み交わすは誰にでも一応通じる（最適ではないだけ）。

| 一致 | 支持したとき | 転向を狙ったとき |
|:---:|:---|:---|
| 満点 | 大成功。大きく時勢が動く | 大成功。自分の勢力が伸び、相手の勢力を削る |
| 一段下 | 成功。時勢が動く。人脈に加わる | **通らない**。転向は全か無かの賭け |
| 二段下 | **手応え。時勢が1だけ動く**（人脈には加わらない） | 何も起こらない |
| ゼロ | 決裂。二度と現れず、**その縁筋も閉じる** | 同左 |

**手応えは常にちょうど1**。ランク補正も、響いた加算も、和解の倍取りも乗らない。
大物を動かせなかった代償（上級−1／伝説−3）はそのまま払う。
読み切れなくても毎ターンが完全な空振りにはならない、というだけの段である。

**「満点」は働きかけによって枚数が違う**（論じる3枚／酌み交わす2枚／肚を割る1枚）。
そして**判定を一段下げる要素はカードの外にもある** ── 警戒、決裂の噂、再訪、
そして金品・肚を割るの読み違え。**転向は一段でも下がれば通らない**ので、
札がすべて刺さっていても、型を読み違えていれば届かない。

手がかりは各人物の**【情勢】描写**と、幕末史の知識。踏み込んだ問いは正解を直接示さず、
選んだカテゴリの不正解カードを一枚消して、残り二択まで絞る。
読み切れないときは一局に一度の**「さらに聞き出す」**で3つの正解をすべて開けられる（獲得−1）。

**短気な者もいる。** 25名は暴力で片をつけようとする。転向を仕掛ければ必ず刃が出て、
**抜き合わせる／言葉で収める／退く**の三択になる。何が通じるかはその人物が望むもので決まる。
切り抜ければ人脈に加わり、誤れば手傷を負う。面会リストに印が出るので、避けることも狙うこともできる。

**旗色を鮮明にするほど、敵対する勢力の人物は耳を貸さなくなる。**
いずれかの時勢が12以上になると、対立する勢力の人物は判定が一段下がる。
寄せ切るか、抑えて回るか——これが最大の判断になる。

### 縁 ― 誰を先に口説いたかが、後半に返ってくる

**人脈の顔は通る。** 会う相手が、すでに【人脈】にいる誰かと**史実の縁**で結ばれていれば、
その名で門が開く。旗色への警戒を受けず、判定は下がらない。

> 〔坂本龍馬の紹介〕「坂本龍馬の見込んだ相手か。試させてもらう。」
> ※ 坂本龍馬の顔が立つ。〔佐幕〕への警戒を受けずに済む

**逆に、決裂させた相手の縁者には悪評が先に届いている**（判定が一段下がる。紹介があれば打ち消される）。

警戒は終盤の問題だ。候補のうち警戒される者は第2ターンで0%、第8ターンで61%になる。
勝っているほど旗色が鮮明になり、耳を貸す相手が減る。**人脈はそこを通るための手形**になる。
序盤に作った縁が、後半になって返ってくる。

### 再訪 ― 決裂した相手は、荒事の場で待っている

**決裂させた相手は、荒事の場（壬生の屯所・夜の街道）へ行くと向こうから来る。**
運では起きない。「そこへ行く」という選択そのものが引き金になる。

> 〔再訪〕暗がりから声がかかる。「探していた。逃げも隠れもせぬ性分は、認めてやる」
> ※ 一度決裂した相手。**説き伏せれば和解し**、出現停止が解けて人脈に加わる

**判定は普通どおり。説き伏せれば和解し、出現停止が解けて人脈に加わる。**
規則はこの2つだけで、判定の上下や特別な報酬はない。
通らなくても失うものはない（相手はもともと二度と現れない）が、その1ターンは戻らない。

通常の面会候補は3名（遠路を直行した日だけ2名）。再訪は**枠がひとつ増える**かたちで出るので、通常枠を潰さない。

### 約束 ― 腹を割って明かした旗は、終局で問われる

**肚を割って通った相手には、そのとき掲げた旗の約束が残る。**
論じて説き伏せただけの相手には残らない。本心を明かした相手にだけ残る。

> → 肚を割って〔開国〕の旗を明かした。**坂本龍馬との約束が残る。**
> この旗が最後に採られていなければ、約束を違えたことになる。

残した約束は時勢チャートに並び、終局の「交わした約束」で一本ずつ問われる。

> **蘭学医**〔開国〕**違えた**
> 「港を開く」と言った者がいた、と語る。港の話になると、そこから先は続けない。

勝ち筋を途中で乗り換えれば点は伸びる。だが乗り換えた先で、
**置いてきた約束の数だけ後味が変わる**。得点には影響しない。効くのは結末の読み味だけだ。

## 第5・第8ターン ― 幕間「政変」

第5ターン（前編）と第8ターン（後編）の開始時に一度ずつ、その時点の上位2勢力の組合せで事件が起きる。
前編は和親条約の調印・将軍継嗣・安政の大獄・桜田門外・池田屋・薩長の密議……と、
**後編より前に起きた出来事**から。**後編の冒頭は、前編で何を選んだかを覚えている。**

> あの『和親条約の調印』で、あなたは**二港だけ開いた**。その余波は、まだ収まっていない。

前編の増減は**合計ゼロ**（誰かが得をすれば、どこかが減る）。どちらへ傾くかを決める場で、
点を配る場ではない。後編は従来どおり大きく動く。
条約勅許、大政奉還の噂、参預会議の決裂、攘夷実行の期日、居留地焼き討ち……
**選択肢に正解はない。**どれを選ぶかが、あなたの立場になる。
さらに各幕間には、その流れを象徴する主要人物が一人現れる。前編と後編で顔が替わり、
固有の一言とカラー肖像によって、同じ数値の増減でも「誰がこの歴史を動かしているか」が残る。

## 到達できる未来は16通り

- **複合革命（通常ルート）**（上位2つの合計が28以上、かつ両方10以上）— **10通り、組み合わせごとに別の未来**
- **単独覇権（高難度ルート）**（いずれか1つの時勢が30以上）— 5通り。到達時は複合より優先
- **混沌**（いずれも満たさない）— 『歴史の藻屑』

時勢チャートには、現在の上位2勢力から届く複合エンドと、先頭勢力の単独エンドを常時表示する。
それぞれ「あと何点か」まで出るので、一勢力を30まで伸ばす以外の勝ち方を見落とさない。

そして結末には、**あなたが築いた人脈のその後**が続く。
同じ『明治維新（史実改）』でも、坂本龍馬を口説いていたか、勝海舟と縁を結んでいたか、
西郷の側に立てなかったかで、最後に読む文章が変わる。

## 決定論エンジン

**同じ seed と同じ選択なら、盤面は必ず同じになる。**
各画面下部の保存コード（`IR9:1868:0:24,0,3,3,511,0;…#1`）を控えれば、その局をいつでも完全に再現・共有できる。

- 盤面を決めるエンジンの乱数は seed 付き mulberry32 のみ。タイトルの初期 seed 生成だけは Web Crypto を使う
- ゲーム全体が `next = step(state, choice)` の純関数
- 登場人物は **151名**（初級30・中級60・上級45・伝説16）。1局で会えるのは約31名
- 名簿数を**素数**にしてあるのは意図的 — 法が合成数だと `gcd(ターン数, 法)` の倍数しか
  基点IDにならず、特定のターンで顔ぶれが潰れる

```sh
node tools/verify.mjs      # 決定論・ルール・初回導線の検証（300項目超）
```

300 seed × 3回実行の state hash 一致、保存コードの往復、判定表とランク補正、
全16エンディングの到達可能性、名簿カバー率、非決定的APIの不在などを自動で確認する。

## 史実フィクションについて

**本作は史実を題材にしたフィクションです。**
人物の勢力分類・性格づけ・台詞・「刺さる動機」は、すべてゲーム上の解釈であり、
史実の評価ではありません。実在の人物・団体への評価を意図するものではありません。

## 原案とこの実装について

原案『維新の乱流』は、AI をゲームマスターとして動かすプロンプトとして
[note で公開されたもの](https://note.com/mickey_bergdol/n/n1c29ef153438)。
本リポジトリは同じ作者による、**LLM を使わない決定論的プログラムとしての再実装**である。

原案からの主な変更点：

- 自由文の説得 → **論証カード式**（3点チェックの採点構造はそのまま）
- 登場人物 100名 → **151名**、紹介枠の偏りを解消
- **対立軸**（旗色を鮮明にすると敵対勢力の人物が警戒する）を追加
- **転向を全か無かの賭け**（通れば獲得+2）に、**決裂で縁筋も閉じる**ように変更
- 複合エンドを3通り → **10通りすべて固有**に
- **相手を調べる**（観る＝所作が読める／訊く＝二択になる、面会ごとに一度ずつ）と**さらに聞き出す奥の手**（全正解、獲得−1、1局1回）を追加
- **来訪**（人脈の誰かが縁筋の人物を連れて訪ねてくる。応じれば移動せず、場の縛りなく四手すべてが使える）
- **混沌**（論破・荒事・決裂で溜まり、溜まるほど世が早く身構える＝警戒線が下がる。人脈の縁があれば通らない）
- 場ごとに**面会人数**が違う（荒事の場は4名、格式のある場は2名）
- 開始時に選ぶ**出自**（3種）。三枠目の面会候補・迎えられ方・こちらの切り出しが変わる
- 無名の周旋家として始まり、行動から現在の呼ばれ方と自身の末路が変わる**主人公の立場**
- 相手の**所作**（3項目×6型×4系統＝72通り）。狙った一項目だけ読めるので、どこを見るかが毎回の判断になる
- 盤面と人物で並びと有無が変わる**面会の入り口**8通り（取り次ぎ／刃の気配／先に問われる／急かされる ほか）
- 実名の人物124名すべてに**余話**。うち35名に関連作品、42名にゆかりの地の地図リンク
- 第5・第8ターンの**幕間「政変」**（前後編各10種×3択、主要人物の顔つき）と、築いた人脈に応じた**後日談**
- 都市間の直行と街道経由を選ぶ**旅程**、複合／単独の残り点を示す**ルート案内**

変更の理由と実測データはすべて [`docs/spec.md`](docs/spec.md) に記録してある。

## 人物の絵を足すには

現在は主要人物8名にカラーの創作肖像があり、それ以外は所属勢力の情景（5枚）が出る。
さらに人物を足す場合は、次の2つを追加する。

1. `assets/portraits/` に WebP を置く
2. `index.html` の `PORTRAITS` に人物ID・パス・画面に出す参照史料を足す

登録した人物は候補一覧に顔が出て、個別面会では勢力色の額と情景を組み合わせて表示される。
残りは従来どおり勢力の情景で代わる。
名簿と実ファイルが食い違えば `node tools/verify.mjs` が落ちるので、片方だけの足し忘れは起きない。

**全151名を描く必要はない。** 面会で会う相手の位には偏りがあるので、上から順に足すと効く。

| 描く枚数 | 面会で本人の絵が出る割合 |
|:---|---:|
| 伝説16名 | 15% |
| 上級以上 61名 | 45% |
| 中級以上 121名 | 77% |
| 全151名 | 100% |

なお151名のうち**95名は実在の人物**（上級・伝説の61名と、初級・中級に混じる近藤勇・桂小五郎・
沖田総司・福沢諭吉ら34名）。残る56名は「茶屋の芸妓」「脱藩した若者」のような**架空の類型**で、
肖像の扱いを気にせず描ける。
