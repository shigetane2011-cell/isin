# 維新の乱流 ― 幕末、日本の夜明けを設計せよ ―

<img src="assets/hero-bakumatsu.webp" alt="幕末の城下と黒船を望み、それぞれの未来を見据える人々" width="760">

幕末を舞台にした歴史設計シミュレーション。戦争も領地経営もない。
**人物の欲望・立場・論理を読み、ときに刃をかわしながら、言葉で歴史を動かす。**

原案は AI をゲームマスターとして動かすプロンプト
（[ミッキーベルグ氏 / note](https://note.com/mickey_bergdol/n/n1c29ef153438)）。
本リポジトリはそのルールを **LLM を使わない決定論的プログラム**として再実装したもの。

## 遊ぶ

**[ブラウザで遊ぶ](https://shigetane2011-cell.github.io/isin/)**

ローカルでは `index.html` をブラウザで開くだけ。ビルド不要、依存なし、通信なし。
画像はすべて同梱され、タイトル・面会中の勢力・到達したエンディングの分だけ読み込む。
初回だけ、正解と人物の返答に基づく根拠を見ながら第1ターンを進めるガイドを任意で選べる。
タイトルの seed は毎回ランダムに用意され、表示後はその値で固定・再現される。

## 30秒でわかる遊び方

1. **どこへ行くか**を選ぶ — 場によって集まる勢力が偏り、使える働きかけが変わる
2. 面会する人物を選ぶ（毎ターン3〜4名が現れる）
3. **支持する**か、**論破して転向させる**かを決める
4. 相手と**対話**する — 面会した瞬間、相手は必ず何か言う。踏み込んだ問いを**一つだけ**ぶつけられる
5. **どう働きかけるか**を選ぶ — 論じる／酌み交わす／金品を贈る／肚を割る
6. **論証カード**を組む — 枚数は働きかけで変わる（3枚／2枚／0枚／1枚）

| 働きかけ | 決定の形 | 上限 | 特徴 |
|:---|:---|:---|:---|
| 論じる | カード3枚 | 大成功 | 最も高く積めるが、読みが要る |
| 酌み交わす | カード2枚（利益・文脈） | 成功 | **杯を交わした相手は刃を抜かない** |
| 金品を贈る | カードなし | 成功 | 確実。探りを1回使う。**大義に生きる者には侮辱** |
| 肚を割る | カード1枚（利益） | 大成功 | 当たれば大きい。外せば決裂＋旗色ごと恥をかく |

### 行き先

| 場 | 集まる者 | 使える働きかけ | 深く刺さる |
|:---|:---|:---|:---|
| 祇園の茶屋 | 公武・抗戦 | 論じる・酌み交わす・肚を割る | 酌み交わす |
| 江戸城中 | 佐幕・公武（中級期から） | **論じるのみ** | 論じる |
| 長崎の商館 | 開国 | 論じる・金品・肚を割る | 金品を贈る |
| 藩邸の書院 | 雄藩・佐幕 | 論じる・肚を割る | 肚を割る |
| 壬生の屯所 | 佐幕・抗戦（荒事） | 論じる・酌み交わす・肚を割る | 肚を割る |
| 夜の街道 | 抗戦・雄藩（荒事） | 論じる・酌み交わす・肚を割る | 酌み交わす |

**同じ場に続けては行けない。** 毎晩同じ茶屋に通えば噂になる。

**響く当たり方は、その者が何を望んでいるかで決まる。**
一緒に飲むほうが早い相手もいれば、物では動かない相手もいる。
対話で望みを訊けば、そのまま働きかけの当たりもつく。

| 一致 | 支持したとき | 転向を狙ったとき |
|:---:|:---|:---|
| 3枚 | 大成功。大きく時勢が動く | 大成功。自分の勢力が伸び、相手の勢力を削る |
| 2枚 | 成功。時勢が動く | **通らない**。転向は全か無かの賭け |
| 1枚 | 何も起こらない | 何も起こらない |
| 0枚 | 決裂。二度と現れず、**その縁筋も閉じる** | 同左 |

手がかりは各人物の**【情勢】描写**と、幕末史の知識。
読み切れないときは**「探る」**で3つの正解をすべて開けられる（獲得−1、1局4回まで）。

**短気な者もいる。** 25名は暴力で片をつけようとする。転向を仕掛ければ必ず刃が出て、
**抜き合わせる／言葉で収める／退く**の三択になる。何が通じるかはその人物が望むもので決まる。
切り抜ければ人脈に加わり、誤れば手傷を負う。面会リストに印が出るので、避けることも狙うこともできる。

**旗色を鮮明にするほど、敵対する勢力の人物は耳を貸さなくなる。**
いずれかの時勢が12以上になると、対立する勢力の人物は判定が一段下がる。
寄せ切るか、抑えて回るか——これが最大の判断になる。

### 縁 ― 誰を先に口説いたかが、後半に返ってくる

**人脈の顔は通る。** 会う相手が、すでに【人脈】にいる誰かと**史実の縁**で結ばれていれば、
その名で門が開く。旗色への警戒を受けず、判定は下がらない。

> 〔坂本龍馬の紹介〕「坂本龍馬の見込んだ相手か。試させてもらう。」
> ※ 坂本龍馬の顔が立つ。〔佐幕〕への警戒を受けずに済む

**逆に、決裂させた相手の縁者には悪評が先に届いている**（判定が一段下がる。紹介があれば打ち消される）。

警戒は終盤の問題だ。候補のうち警戒される者は第2ターンで0%、第8ターンで61%になる。
勝っているほど旗色が鮮明になり、耳を貸す相手が減る。**人脈はそこを通るための手形**になる。
序盤に作った縁が、後半になって返ってくる。

## 第8ターン ― 幕間「政変」

第8ターンの開始時に一度だけ、その時点の上位2勢力の組合せで事件が起きる。
条約勅許、大政奉還の噂、参預会議の決裂、攘夷実行の期日、居留地焼き討ち……
**選択肢に正解はない。**どれを選ぶかが、あなたの立場になる。

## 到達できる未来は16通り

- **単独覇権**（いずれか1つの時勢が30以上）— 5通り
- **複合革命**（上位2つの合計が30以上、かつ2番目が10以上）— **10通り、組み合わせごとに別の未来**
- **混沌**（いずれも満たさない）— 『歴史の藻屑』

そして結末には、**あなたが築いた人脈のその後**が続く。
同じ『明治維新（史実改）』でも、坂本龍馬を口説いていたか、勝海舟と縁を結んでいたか、
西郷の側に立てなかったかで、最後に読む文章が変わる。

## 思想を示す五色

面会・人物カード・時勢チャート・幕間・交渉結果・エンディングで同じ色体系を使う。
複合勢力の人物と複合エンドは、二つの色を左右から重ねて表示する。
面会後は一枚絵の細縁、人物名の見出し座布団、本文の引用線にも同じ色を通し、
和紙と墨の雰囲気を保ったまま、現在向き合っている思想を一目で判別できる。

| 思想 | キーカラー |
|:---|:---|
| 公武合体 | 紫 |
| 開国通商 | 青 |
| 佐幕守旧 | 緑 |
| 雄藩連合 | 金・黄土 |
| 尊皇攘夷・抗戦 | 赤 |

面会には5勢力の情景、結末には**全16通りそれぞれ固有の一枚絵**を用意してある。

## 決定論エンジン

**同じ seed と同じ選択なら、盤面は必ず同じになる。**
各画面下部の保存コード（`IR4:1868:24,0,3,3,511,0;…#1`）を控えれば、その局をいつでも完全に再現・共有できる。

- 盤面を決めるエンジンの乱数は seed 付き mulberry32 のみ。タイトルの初期 seed 生成だけは Web Crypto を使う
- ゲーム全体が `next = step(state, choice)` の純関数
- 登場人物は **151名**（初級30・中級60・上級45・伝説16）。1局で会えるのは約31名
- 名簿数を**素数**にしてあるのは意図的 — 法が合成数だと `gcd(ターン数, 法)` の倍数しか
  基点IDにならず、特定のターンで顔ぶれが潰れる

```sh
node tools/verify.mjs      # 決定論・ルール・初回導線の検証（182項目）
```

300 seed × 3回実行の state hash 一致、保存コードの往復、判定表とランク補正、
全16エンディングの到達可能性、名簿カバー率、非決定的APIの不在などを自動で確認する。

## 余話

**実名の人物124名すべて**に、史実側の短評を添えてある。
うち35名には関連作品（司馬遼太郎作品、大河ドラマ、当人の著作など）を、
42名には**ゆかりの地のGoogleマップリンク**を付けた。対話画面から開閉式で読める。

> **有村次左衛門** — 薩摩藩士。桜田門外の変で井伊直弼を討ち取り、自らも深手を負って自刃した。
> ゆかりの地：[桜田門 東京 を地図で見る ↗]

遊んだあとに実際の人物を知り、実際に足を運ぶための入口として置いてある。
残る27名は「茶屋の芸妓」「瓦版売り」といった匿名的な役柄なので、余話は付けていない。

地図リンクは**押したときだけ**外部サイトを開く。ページ自体は外部リソースを一切読み込まない。

## 史実フィクションについて

**本作は史実を題材にしたフィクションです。**
人物の勢力分類・性格づけ・台詞・「刺さる動機」は、すべてゲーム上の解釈であり、
史実の評価ではありません。実在の人物・団体への評価を意図するものではありません。

## 原案とこの実装について

原案『維新の乱流』は、AI をゲームマスターとして動かすプロンプトとして
[note で公開されたもの](https://note.com/mickey_bergdol/n/n1c29ef153438)。
本リポジトリは同じ作者による、**LLM を使わない決定論的プログラムとしての再実装**である。

原案からの主な変更点：

- 自由文の説得 → **論証カード式**（3点チェックの採点構造はそのまま）
- 登場人物 100名 → **151名**、紹介枠の偏りを解消
- **対立軸**（旗色を鮮明にすると敵対勢力の人物が警戒する）を追加
- **転向を全か無かの賭け**に、**決裂で縁筋も閉じる**ように変更
- 複合エンドを3通り → **10通りすべて固有**に
- **対話**（踏み込んだ問いを一つだけ）と**探る**（獲得−1、1局4回）を追加
- 実名の人物124名すべてに**余話**。うち35名に関連作品、42名にゆかりの地の地図リンク
- 第8ターンの**幕間「政変」**（10種×3択）と、築いた人脈に応じた**後日談**

変更の理由と実測データはすべて [`docs/spec.md`](docs/spec.md) に記録してある。
