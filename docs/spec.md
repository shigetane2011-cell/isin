# 『維新の乱流』決定論版 — 仕様書

原作: [【新作！ SLG】『維新の乱流』― 幕末、日本の夜明けを設計せよ ―](https://note.com/mickey_bergdol/n/n1c29ef153438)（ミッキーベルグ氏）

原作は AI をゲームマスターとして動かすプロンプトである。本リポジトリは、そのルールを
**LLM を一切使わない決定論的なプログラム**として再実装したものである。

---

## 1. 決定論の契約

| 項目 | 内容 |
|:---|:---|
| エンジン乱数 | seed 付き mulberry32 のみ。`Math.random` / `Date.now` / `new Date` は使用しない |
| 状態 | `seed + 選択列` だけで盤面が一意に決まる |
| 保存 | 保存コード `IR4:<seed>:<選択>;…#<幕間>` が完全なセーブデータ兼リプレイデータ |
| 検証 | `node tools/verify.mjs` が300局×3回実行して state hash の一致を確認する |

乱数の流れは `streamOf(seed, turn, salt)` で用途ごとに独立させてある。呼び出し順序が
変わっても結果が変わらないため、UI の変更が盤面に影響しない。
タイトル画面の初期 seed だけは Web Crypto で生成する。生成した数値を画面に表示してから
`createState(seed)` へ渡すため、開始後の盤面・保存コード・リプレイは従来どおり完全決定論である。

## 2. 原作からの変更点

### 2-1. 説得判定 → 論証カード式（最大の変更）

原作の Step 2「3点チェック（利益提示・文脈理解・論理整合）」は、プレイヤーの自由文を
AI が読んで採点するものであり、LLM なしでは実行できない。そこで**自由入力を有限の選択に
落とした**。

- 3つのカテゴリ（利益提示 / 文脈理解 / 論理整合）ごとに、提示された4枚から1枚選ぶ
- 各人物は「刺さる動機の型」を3つ持つ（隠しデータ）
- **一致数がそのまま原作の得点になる**: 3 = 大成功 / 2 = 成功 / 1 = 失敗 / 0 = 決裂

採点構造は原作のまま。手がかりは各人物の【情勢】描写と、幕末史の知識である。

### 2-2. 動機の型とカードプール

動機の型は全勢力共通で各カテゴリ6種（計18種）。

| | 0 | 1 | 2 | 3 | 4 | 5 |
|:---|:---|:---|:---|:---|:---|:---|
| 利益提示 | 名誉・武名 | 金銭・利権 | 安全・保身 | 大義・理念 | 力・武備 | 知・学問 |
| 文脈理解 | 家門・血筋 | 主君への義理 | 民草の暮らし | 列強の圧力 | 同志の死 | 出自の低さ |
| 論理整合 | 目的と手段 | 段階論 | 力の均衡 | 名分論 | 実利優先 | 時勢・必然 |

カード本文は **5勢力 × 3カテゴリ × 6型 = 90枚**。

**人物に刺さる型は不変で、どの思想の言葉で語るか（勢力）だけが立場によって変わる。**
近藤勇は佐幕を説こうと開国を説こうと「名誉」に反応する。支持なら本人の勢力、転向なら
主張する勢力のカードプールが使われる。

### 2-3. 基点IDの「直前の入力総文字数」

原作は `(直前の入力総文字数 × ターン数)` の下2桁を基点IDとする。自由入力をやめたため、
**組み上がった論証文（カード3枚を「。」で連結した文）の文字数**をこれに充てた。
原作の計算式をそのまま保ったうえで完全に決定論的になり、「自分の選択が次の面会者を変える」
因果も残る。第1ターンのみ直前の入力が存在しないため、seed から導出する。

原作の「下2桁」は名簿が100名だったことに由来する（＝ `% 100`）。名簿を151名に広げたため、
法をそこに合わせてある（`% 151`）。**名簿数を素数にしてあるのは意図的**で、法が合成数だと
`gcd(ターン数, 法)` の倍数しか基点にならない。たとえば法150・ターン10では基点が10の倍数
15通りに潰れ、そのターンは毎回ほぼ同じ顔ぶれになってしまう。素数なら、どのターンでも
基点が全域に散る。

| 法 | 全ターンで到達する基点ID | ターン別の到達数 |
|:---|---:|:---|
| 100（原作） | 88 / 100 | 31,31,25,20,31,31,25,31,**10** |
| 150 | 108 / 150 | 31,31,31,29,25,31,31,31,**15** |
| **151（採用）** | **141 / 151** | 31,31,31,31,31,31,31,31,31 |

### 2-4. 人物名簿：100名 → 151名

原作は「人となり・ジレンマをアドリブ生成」＝ LLM の仕事。書き置きに変えたうえで、
各人物に **二つ名 + 情勢描写 + 刺さる型3つ** を持たせた。カード本文は共通プール
から引く（2-2）。情勢描写は、その人物に何が刺さるかを読み取るための手がかりを兼ねる。

名簿は原作の100名から **151名** に拡張した（初級30・中級60・上級45・伝説16）。
1局で会えるのは約31名なので、100名では実測で95名しか使われず、5名は永久に登場しなかった。

ID体系は「IDが大きいほど高ランク」を保つため、既存の人物IDを次のように移してある。

| 帯 | 旧ID | 新ID | 人数 |
|:---|:---|:---|---:|
| 初級 | 01〜30 | 01〜30（変更なし） | 30 |
| 中級 | 31〜70 | 31〜70（変更なし）＋ 71〜90（追加） | 60 |
| 上級 | 71〜90 | 91〜110 ＋ 111〜135（追加） | 45 |
| 伝説 | 91〜100 | 136〜145 ＋ 146〜151（追加） | 16 |

初級を増やさなかったのは、原作の「最初は雑兵、やがて英雄」の立ち上がりを保つため。
ランク補正 `(元のID % 30) + 1` が初級=ID01〜30 を前提にしているため、この帯は動かせない。

**保存コードの版**は、名簿拡張時に `IR1` → `IR2`、その後のルール変更で `IR3`、
幕間の導入で `IR4` と移ってきた。現在読み込めるのは `IR3` と `IR4` の2つ。
`IR3` は幕間より前の版なので、幕間を「未選択」として扱えばそのまま完全に再現できる。
`IR1` `IR2` は人物IDが移る前のもので現在の盤面を再現できないため、エラーで弾く。

### 2-5. 紹介枠の偏りの解消

原作の優先順位 ①未獲得 ②史実の結びつき ③より高ランク のうち、③を「常に最高ランク」と
実装すると、決定論ゆえ**毎回まったく同じ大物しか出ない**。実測で、紹介枠8478回に登場したのは
33名だけ、うち上位4名（和宮・徳川慶喜・孝明天皇・勝海舟）で53%を占めていた。

そこで③を**重み付き抽選**に変えた（初級1・中級4・上級9・伝説16）。大物ほど来やすい性質は
保ったまま、局ごと・ターンごとに顔ぶれが変わる。あわせて、`TIES` に片側だけ書いた縁を
**双方向グラフとして扱う**ようにした（近藤勇→沖田総司 と書けば、沖田総司→近藤勇 も成立する）。

| | 改修前 | 改修後 |
|:---|---:|---:|
| 紹介枠に登場する異なり人数 | 33名 | **142名** |
| 上位4名の占有率 | 53% | **16%** |

### 2-6. ビジュアル

墨・和紙を基調に、タイトル・面会・エンディングへ1600×640のWebPビジュアルを使用する。

- `assets/hero-bakumatsu.webp`：タイトル・OGP
- `assets/factions/`：公武・開国・佐幕・雄藩・抗戦の5枚。面会相手の所属に連動
- `assets/endings/`：単独5・複合10・混沌1の全16枚。判定結果に連動
- `assets/portraits/`：主要人物8名の創作彩色肖像。候補一覧・個別面会・幕間に使用

思想は、公武＝紫・開国＝青・佐幕＝緑・雄藩＝金／黄土・抗戦＝赤に固定する。
人物カード、時勢チャート、面会画像の色レイヤー、幕間、交渉結果、エンディング画像で同じ色を使う。
複数勢力の人物と複合エンドは二色のグラデーションにし、現在どの思想へ向かっているかを
文章を読まずとも判別できるようにする。
面会・論証・結末の本文パネルは、見出し背景と引用線を該当色で薄く染める。
一枚絵は焦茶の外周に勢力色の細縁を重ね、色面積を抑えて時代物の質感と即時識別を両立する。
主要人物の肖像は史料写真・肖像画の顔立ちを参照し、人物ごとの所属色で彩色する。
候補一覧では小さな顔写真として識別を助け、個別面会では所属勢力の情景と組み合わせた額装表示にする。
創作彩色であることと参照史料の種別は画面上に明記し、史料そのものと誤認させない。

画像の総量は約3.6MBだが、一括では読み込まない。タイトルは1枚、面会は該当勢力と
該当する主要人物の肖像のみ、
エンディングは到達した1枚だけを遅延／オンデマンドで読み込む。画像が失敗しても和紙色の
背景と勢力名が残り、ゲームの操作・判定・セーブコードには影響しない。

## 2-7. ゲーム設計上の追加ルール（原作からの意図的な変更）

実装後に自動プレイで測ったところ、**戦略を決めた時点でエンディングが100%確定**していた。
第1ターンで目標勢力を決めたら、残り9ターンに戦略的な意思決定が存在しない状態だった。
内訳の問題は4つで、それぞれに対応する規則を入れてある。

### A. 転向は3枚一致でのみ通る

**問題**: 転向は「主張勢力+N かつ 相手勢力−1/−2」で、支持の「関係ない勢力+N」より常に得。
立場の選択が「相手が目標勢力か否か」で機械的に決まり、判断が存在しなかった。

**規則**: 転向は攻撃なので、**満点でしか通らない**。一段でも下がれば失敗扱いで、
人脈にも加わらない。支持は従来どおり一段下でも通る。

満点の枚数は働きかけで変わる（論じる3枚／肚を割る1枚。金品では転向できない）。
また判定を下げる要素はカードの外にもあるため、**置いた札がすべて刺さっていても
転向が通らないことがある**（後述 R）。

これで、支持は「確実だが伸びるのは相手の勢力」、転向は「当てにくいが自分の勢力が伸びる」
という非対称な選択になる。目標勢力の人物を面会リストから拾う価値も生まれる。

### B. 対立勢力の警戒（旗色を鮮明にする代償）

**問題**: 5つの時勢が互いに無関係な独立カウンタで、史実の対立構造が反映されていなかった。

**規則**: 史実で真っ向からぶつかった組み合わせを対立関係として持ち、**自分の盤面で
相手の対立勢力が12以上に育っていると、その人物は端から警戒し、判定が一段下がる**
（大成功→成功、成功→失敗）。決裂までは落とさない。

| 勢力 | 対立する勢力 | 理由 |
|:---|:---|:---|
| 公武 | 抗戦・開国・雄藩 | 融和路線と過激攘夷 / 攘夷志向の朝廷 / 倒幕へ傾く大藩 |
| 開国 | 抗戦・公武 | 開国か攘夷か |
| 佐幕 | 雄藩・抗戦 | 幕府か倒幕か / 新選組と志士 |
| 雄藩 | 佐幕・公武 | |
| 抗戦 | 佐幕・開国・公武 | |

対立していない組み合わせは 公武+佐幕・開国+雄藩・開国+佐幕・雄藩+抗戦 の4つで、
うち2つは原作が定めた複合エンドの組み合わせと一致する。

**これは原作の「どの勢力を伸ばしても熱量は上がる」という中立的な設計思想を変える規則である。**
原案と実装は同じ作者によるもので、この変更は作者の判断で入れている。
原案のプロンプト版をそのまま遊びたい場合は `WARY_LINE` を 99 にすれば無効化できる。

閾値12は実測で決めた。10だと『公武+抗戦』の複合が32%まで落ちて一部のエンディングが
実質不可能になり、15以上だと無策のプレイでもほぼ100%通ってしまい警戒が機能しない。

### C. 決裂すると縁筋も閉じる

**問題**: 初級・中級の決裂は時勢の増減ゼロで、名簿151名のうち1名が消えるだけ。
損失がほぼゼロなので、序盤は当てずっぽうで撃ち続けても罰がなかった。

**規則**: 決裂した人物と縁のある人物は、**以後の紹介枠に出てこない**。近藤勇と決裂すれば、
土方・沖田・永倉・斎藤・伊東・山南への紹介経路がまとめて絶える。
原作の「出現停止」の自然な拡張であり、人脈システムに初めて重みが出る。

### F. 複合エンドは二番目の勢力にも実体を要求し、通常の勝ち筋にする

**当初の問題**: 複合革命の条件が「上位2つの合計30以上」だけだったため、29+1 でも複合扱いになった。

**現在の規則**: **上位2つの合計28以上、かつ両方10以上**を複合革命とする。
満たさない場合は連立の実体がないものとして『歴史の藻屑』になる。単独覇権は従来どおり30以上で、
こちらは高難度ルートとして複合より先に判定する。

プレイテストで「30まで一つを伸ばす以外のやり方に気づかなかった」と分かったため、
時勢チャートに現在の上位2勢力の複合エンドと先頭勢力の単独エンドを並べ、どちらも残り必要点を表示する。
複合を2点だけ低くしたのは、二勢力を各10以上にする過程で警戒と候補の分散を受けるぶんを補い、
複合を抜け道ではなく標準の勝ち筋にするためである。

### 効果（自動プレイ実測・成功率＝歴史の藻屑以外に到達した割合）

| 腕前 | 素朴に一勢力へ寄せる | 警戒を避け、支持を優先する |
|:---|---:|---:|
| カード全問正解 | 78% | **100%** |
| 上手（文脈80%/論理80%） | 60% | **83%** |
| 普通（文脈70%/論理60%） | 33% | **48%** |
| 下手（文脈50%/論理40%） | 8% | 12% |

改修前は素朴な寄せでも100%だった。いまは**戦略の巧拙がカード数枚分の価値を持つ**。
全10エンディングは、警戒を避ける熟練プレイでいずれも到達可能であることを検証済み。

### G. 「探る」と、難易度そのものの調整

実際に遊んで「難しすぎる」との指摘があり、現実的な腕前を仮定して測り直した。
それまでの測定は「利益提示は情勢描写から必ず読める（正答率100%）」という
甘い前提だったが、人間は利益提示も外す。仮定を現実に寄せると素の成功率は
**名手91% / 上手59% / 普通16% / 初心者1%** で、確かに厳しすぎた。

**規則1: 候補カードを各カテゴリ4枚 → 3枚に減らす。**
当てずっぽうの正答率が25%→33%に上がり、読む量も減る。これだけで
普通の腕前が16%→37%になる。

**規則2: 「探る」（1局4回まで、探った交渉は獲得 −1）。**
探ると3つの正解がすべて開示される。代わりに手の内を明かした分だけ影響力が落ち、
その交渉で得られる時勢が1下がる。

代償の設計には試行錯誤が要った。測定した案と結果：

| 代償の形 | 結果 |
|:---|:---|
| 箇所ごとに −1 | 全部探ると **0%**。1ターン−2は10ターンで目標の2/3を失う |
| 探れば一律 −1（無制限） | 全部探ると **99%**（腕前を問わず）。確実な大成功を無限に買える |
| 大成功→成功に格下げ | 全部探ると **0%**。確実な成功だけでは25点前後で頭打ち |
| **一律 −1・1局4回まで** | **採用**。総量が縛られるので確実性を買っても勝ちきれない |

整数の代償では0%か99%にしか着地しない。**確実な正解を無制限に売る限り、
必ず全か無かになる**ためで、回数制限が本質的な解になった。

上限4回は掃引で決めた（2回=45% / 3回=47% / 4回=52% / 無制限=99%、普通の腕前）。

**副産物**: 代償が固定−1なので、元の獲得が大きい相手ほど相対的な損は小さい
（初級 4→3＝75%が残る、伝説 8→7＝88%が残る）。**探りは大物と、
失敗できない転向に取っておくのが得**という判断が自然に生まれ、
未解決だった「大物を早く呼ぶ動機がない」問題にも部分的に効いた。

### H. チップ式の対話

面会した相手には、**踏み込んだ問いを一つだけ**ぶつけられる。返答はその人物の
「刺さる型」をそのまま語るので、対応するカードが読める。世間話（時勢をどう見るか、
こちらをどう見ているか）は何度でも聞けるが、型の手がかりにはならない。

これは無料だが部分的なヒントで、有料・全開示の「探る」との間に段を作る。

| 問い | 分かること |
|:---|:---|
| 何を望んでおられる | 利益提示の正解 |
| いま何に縛られておられる | 文脈理解の正解 |
| 何を筋とお考えか | 論理整合の正解 |

**一問に絞ったのは実測による。**

| 聞ける数 | 名手 | 上手 | 普通 | 初心者 |
|:---|---:|---:|---:|---:|
| 0問 | 97% | 76% | 37% | 5% |
| **1問（採用）** | 98% | 91% | **75%** | **39%** |
| 2問 | 98% | 97% | 94% | 84% |
| 3問 | 97% | 97% | 97% | 97% |

二問聞けると初心者でも84%通ってしまい、腕前の差がほぼ消える。三問だと全員97%で
ゲームが成立しない。一問なら難易度が下がりつつ差は残る。

返答は **3カテゴリ × 6動機型 = 18通り**の共通台詞。同じ動機型の人物には同じ台詞が返るが、
これは欠点ではなく、繰り返し聞くことで「名誉とはこういう物言いだ」と型を覚えられる。

対話はゲームの数値に一切影響しないため、状態にも保存コードにも記録していない。
リプレイでは何を訊いたかは再現されないが、結果は完全に一致する。

### 効果（最終形・現実的な腕前での成功率）

| 探り方 | 名手 | 上手 | 普通 | 初心者 |
|:---|---:|---:|---:|---:|
| 一切探らない | 97% | 76% | 37% | 5% |
| 毎ターン探る（4回で尽きる） | 95% | 79% | 48% | 15% |
| **大物と転向に取っておく** | 97% | **84%** | **53%** | **19%** |
| 終盤にまとめて使う | 96% | 82% | 54% | 18% |
| （改修前・参考） | 91% | 59% | 16% | 1% |

※ この表は対話（H）を使わない場合。対話で一問聞くと、普通の腕前で 37% → 75%（探りなし）、
53% → 82%（探りも賢く使う）まで上がる。

探りを賢く使うと普通の腕前で+16ポイント。使い方の巧拙でも差が出る（53% vs 48%）。
名手の97%は変わらないので、上限は下がっていない。

### I. 公開前の指摘への対応

### L. 幕間「政変」と後日談

外部レビューで「151人いても結末にはメーターしか反映されない」と指摘された。
確認したところ事実で、`evaluateEnding(st)` は `st.currents`（5つの数値）しか見ておらず、
`contacts` も `banned` も一切参照していなかった。誰を人脈に加えても結末は同一だった。

**幕間「政変」（第5・第8ターン）**

第5・第8ターンの開始時に一度ずつ、その時点の上位2勢力の組合せで事件が起きる。
選択肢は3つで、正解はない。価値観を問うもので、**盤面をわずかに動かし、
結末に固有の一段落（`after`）を書き加える**。同じ最終勢力でも、3択ごとに読む文章が変わる。
各回には `INTERLUDE_FIGURES` から主要人物を一人出し、カラー肖像・固有の一言・人物名を添える。
新しい人物別判定は増やさず、数値だけに見えたルートへ「誰が動かしている歴史か」を与える。

幕間の増減で時勢が上限40に達した場合は、交渉と同じくその時点で終局とする。

導入前に構造上の懸念を2つ測ったが、どちらも成立しなかった。

| 懸念 | 実測（2000局） |
|:---|:---|
| 時勢40で早期終了する局があり、第8ターンに届かないのでは | 早期終了は1%、第8ターン未到達は**0%** |
| 第8ターンの上位2勢力は最終結果とズレるのでは | 第5・第8ターンとも最終と**100%一致** |

ただし後者は「最初から同じ勢力を狙い続ける」シミュレーションでの数字で、
途中で方針を変える人間のプレイでは一致率が落ちる。幕間はその時点の情勢を描くものなので、
結末と食い違っても物語上の破綻にはならない。

**後日談**

エンディングの末尾に、獲得した人脈の後日談を出す。
「その人物の勢力が最終的に採られた側にいたか」で2通りに分かれる（混沌エンドでは全員が負け側）。
ランクの高い順に5名まで個別に語り、残りは名前だけ挙げる。

上級・伝説の61名には個別の後日談を書き、中級・初級は勢力別のひな型で語る。
ランク順に表示するため、実際に個別文が出るのはほぼ上級以上になる。

**採用しなかった提案の一部**

レビューは幕間を第5・第8・第10ターンの3回とし、決裂した人物による分岐も提案していたが、
このうち**決裂ベースの分岐は入れていない**。1局あたりの決裂は実測で**平均0.0名**で、
まともに遊べば起きないためである（決裂は3枚とも外した場合のみ）。
書いても上手いプレイヤーには一生表示されない。

幕間も3回ではなく1回にした。テンポへの影響が最も大きい変更なので、
1回で手応えを見てから増やすほうが判断しやすい。

**保存コード**

幕間の選択を含むため `IR4` に上げた。ただし `IR3` も読み込める。
IR3 は幕間の追加より前の版なので、幕間を「未選択」として扱えばそのまま完全に再現される。
幕間番号は `0〜2` 以外を、seed は数値以外をエラーで弾く。

**後日談の書き方**

代替史のゲームなので、後日談に「初代の内閣総理大臣となり」のような**明治固有の官職・事績**を
書くと、徳川が勝った世界でも同じ文が出て破綻する。11名分をこの観点で書き直し、
検査をテストに入れた（内閣総理大臣・維新三傑・元老・司法卿・内務卿・太政大臣などを禁止語とする）。

### M. 開口一番と立ち合い

**開口一番**：面会した瞬間に相手が発する一言を、**151名すべてに固有で**持たせた。
三人称の情勢描写だけだった面会画面に、その人物の声が入る。

> 近藤勇「……拙者は多摩の百姓の出だ。それを承知で来られたか。」
> 中村半次郎「おいは学がなか。……難しか言葉は使わんでたもんせ。」
> 吉田松陰「諸君、狂いたまえ。……で、あなたは狂えるか。」

**立ち合い**：短気な人物25名に、暴力で解決しようとする性質を持たせた。
懸念された「分岐が増えすぎる」問題は、次の3点で回避している。

1. **新しい枝を作らず、既存の交渉結果に接ぎ木する。** 転向を仕掛けたときは必ず、
   支持なら通らなかったときだけ刃が出る。交渉の判定系はそのまま。
2. **正解は既存の「利益の型」から導く。** 名誉・武備は力に、大義・学問は言葉に、
   金銭・保身は間合いに応じる。対話や探りで型を掴んでいれば切り抜けられるので、
   新しい知識体系を覚える必要がない。
3. **文章は人物ごとに持たない。** 応じ方3通り × 勝敗の6文だけを共有する。
   151名分の戦闘描写は書いていない。

| 応じ方 | 通じる相手（利益の型） |
|:---|:---|
| 抜き合わせる | 名誉・武名 / 力・武備 |
| 言葉で収める | 大義・理念 / 知・学問 |
| 退く | 金銭・利権 / 安全・保身 |

切り抜ければ腕を認められて**人脈に加わる**。誤れば手傷を負い、
**主張していた勢力 −3・探り1回を失い・その人物は出現停止**になる。

**遭遇頻度はプレイヤーが決める。** 面会リストに「気が短い」と明示してあるので、
避けることも狙うこともできる（上手の腕前で実測）。

| 方針 | 立ち合い | 成功率 |
|:---|---:|---:|
| 短気な相手を避ける | 0.0回/局 | 69% |
| 成り行きに任せる | 0.4回/局 | 82% |
| 短気な相手を狙って転向 | **4.1回/局** | **33%** |

狙えば大幅に成功率が落ちるので、無料の見せ場にはなっていない。

**保存コード**は各行の7番目に応じ方（0〜2）を足した。省略可なので、
立ち合い導入前の `IR4` コードもそのまま読める（その場合は立ち合いが起きなかったものとして扱う）。

### O. 縁が判定に効く（人脈の顔と、決裂の悪評）

**問題**: `TIES`（史実の縁、133名・289本）は紹介枠の選出に使われていたが、プレイヤーからは
完全に不可視だった。面会の札には「[人脈] ご紹介にあずかりました」としか出ず、
誰の紹介なのかも、それに意味があるのかも分からない。

実測すると、この不可視の機構はすでに勝敗を左右していた。**「縁のある候補を優先して会う」
だけで成功率は 上手 37% → 79%、名手 80% → 99%。** ゲームで最も強い戦略が、
画面に一言も出ていなかったことになる。

**規則**:

- `vouchOf(st, id)` — 人脈の誰かと縁があれば、その人物を返す。紹介枠に限らない。
  縁のある者はどの枠に出ても、あなたを門前払いしない。
- `grudgeOf(st, id)` — 決裂させた相手と縁があれば、その人物を返す。
- 紹介があれば、**旗色への警戒（B）は通らない**。
- 悪評が届いていれば**一段下がる**。紹介があれば打ち消される。
- どちらも決裂までは落とさない（`raw >= 2` のときだけ効く。警戒と同じ扱い）。
- 面会の札と、相手と向き合う画面の両方に、縁者の名・一言・効果を明示する。
  同じ画面で言い回しが重なったときは台詞を省く。

**なぜ「警戒を打ち消す」効果なのか**: 警戒が終盤の問題だから。候補のうち警戒される者の割合は
第2ターン 0%、第4ターン 2%、第6ターン 14%、第8ターン 61%、第10ターン 67%（名手）。
勝っているほど旗色が鮮明になり、耳を貸す相手が減る。人脈はそこを通る手形になる。
序盤には価値がなく終盤に効くので、**縁を作った動機が、作った直後ではなく後半に返ってくる**。

**効果**（選び方を揃えた比較。どちらも「縁のある候補を優先」／各600局）

| 腕前 | 判定に効かない | 判定に効く |
|:---|---:|---:|
| 名手 (1.0) | 99% | 100% |
| 上手 (0.8) | 79% | 84% |
| 普通 (0.5) | 14% | 16% |
| 初心 (0.2) | 1% | 1% |

上げ幅は +1〜5pt に収まる。当初は「79% → 100%」と測って効き過ぎと判断し、上限を4通り
（人脈の直近N人だけ／1局N回まで／紹介者と同勢力のときだけ）試したが、いずれもほぼ効かなかった。
原因は測り方にあり、比較対象の「縁なし」版では選び方まで変わってしまっていた
（`vouchOf` を潰すと「縁のある候補を優先」戦略そのものが無効になる）。
選び方を揃えて測り直すと差は小さく、上限は不要だった。

**副作用**: `duelPending` は `scoreOf < 2` で発火するため、紹介のある相手は刃を抜きにくくなる。
「顔の立つ相手には斬りかからない」は意図に沿うので、そのまま残した。

**内訳の集約**: 判定の下げ幅とその理由を `scoreBreakdown` 1か所にまとめ、`scoreOf` は
その `score` を返すだけにした。従来、結果画面の「警戒により一段下げられました」は
実際には下がっていない場合（1枚一致など）にも表示されていた。実際に効いた下げだけを
`waryApplied` / `grudgeApplied` として報告するようにしてある。

### P. 約束（肚を割って明かした旗が、終局で問われる）

**問題**: 10ターンの各手は独立していて、途中の選択が終局の語り口に返ってこない。
`contacts` は結末で「その後の人々」に出るが、**あなたが何を言ったか**は一切残らない。

**規則**:

- **肚を割る（働きかけ3）で通った相手**には、そのとき掲げた旗（`argueF`）の約束が残る。
  `promises: [{id, f}]` を状態に持つ。同じ相手に二度は残らない。立ち合いに敗れて
  出現停止になった相手にも残らない。
- 終局で `winningFactions(ending)` にその旗が含まれなければ**約束を違えた**ことになる。
  混沌エンドではすべて違えたことになる。
- 得点・判定・エンディング分岐には**一切影響しない**。変わるのは結末の語り口だけ。
- 時勢チャートに【残した約束】として常時表示し、結果画面でも残した瞬間に明示する。

**なぜ肚を割るだけなのか**: 「こちらの旗色も明かす」働きかけだから。論じて説き伏せた相手には
本心を告げていない。約束は、腹を割った相手にだけ生まれる。論じる一辺倒で通した打ち手には
約束が一つも残らないが、それは**誰にも本当のことを言わなかった**という結末として正しい。

**頻度**（400局・自動プレイ実測）

| 打ち方 | 肚を割る | うち通った＝約束が残る |
|:---|---:|---:|
| 相手の型に合わせる（推奨の打ち方） | 2.5回/局 | 1.3〜2.5回 |
| 肚を割るを常に選ぶ | 9.0回/局 | 5.5〜8.9回 |
| 論じる一辺倒 | 0回 | 0回 |

型に合わせて打てば1局に1〜2本。少なく、覚えていられる数に収まる。
肚を割るを乱発すれば約束は増えるが、名手でも大成功が 9.5回 → 3.2回 に落ちる
（カード1枚に賭けるため）。**約束を集めようとすると勝てなくなる**という形で釣り合っている。

**保存コードは変えていない**。約束は行動から導けるので、欄を増やす必要がなかった。
旧版の保存コードもそのまま読め、再生すると約束まで再現される。

**同文の回避**: 約束の後日談は5勢力 × 果たした／違えた × **3通り**持ち、同じ画面で
言い回しが重なったらずらす。同じ理由で、無名の人物の後日談ひな型（`FATE_TEMPLATE`）も
2通り → 3通りに増やした。同勢力の人物が並んだときに同じ文が続いていたため。

**混入の検査**: 生成の過程で日本語のつもりの箇所にキリル文字が紛れ込む事故が複数回あった。
151名分の台詞を毎回目視するのは現実的でないので、`index.html` / `README.md` / `docs/spec.md`
にキリル・ギリシャ・アラビア・ヘブライ文字が無いことを verify で常に検査するようにした。

### Q. 再訪（決裂した相手が、荒事の場で待っている）

**問題**: `banned` は完全な死に札だった。決裂させた相手は二度と現れず、縁筋も閉じるだけで、
取り返す道がない。うまく打てない人ほど盤面が痩せていく一方になる。

当初これは「決裂は名手で平均0.0回/局なので死に機能になる」と判断して見送った。
**この見立てが誤っていた。** 腕前ごとに測り直すと：

| 腕前 | 決裂者/局 | 決裂が起きる局 | 最初の決裂 | 荒事の場で決裂者を抱えたターン |
|:---|---:|---:|---:|---:|
| 名手 (1.0) | 0.0名 | 0% | — | 0.0回 |
| 上手 (0.8) | 0.5名 | 39% | T5.2 | 0.6回 |
| 普通 (0.5) | 1.6名 | 82% | T4.1 | 1.7回 |
| 初心 (0.2) | 3.8名 | 98% | T2.6 | 2.8回 |

名手が見ないだけで、**普通の打ち手の82%・初心の98%が決裂を経験している**。
上振れした打ち手の数字で機能の要否を判断していた。

**規則**:

- `revisitOf(st, place)` — 荒事の場（`hot`）で、`banned` があれば**直近に決裂させた一人**を返す。
  乱数を使わない。「荒事の場へ行く」という選択そのものが引き金になる。
- 再訪は `meetingList` の**枠を増やす**かたちで出る（通常3枠、遠路直行時2枠＋紹介枠＋再訪枠）。
  通常枠を潰さないので、無視しても損はしない。
- 判定は**一段重い**。本人が怒っているので、`vouchOf`（紹介の顔）では消えない。
  結果として **3枚すべて刺さってようやく成功**し、大成功には届かない。
- 通れば獲得は**倍**。`banned` から外れて人脈に加わり、次の決裂者が待つようになる。
- 通らなくても失うものはない（もともと二度と現れない相手）。失うのは1ターンだけ。

**効果**（選び方を揃えた比較・各600局）

| 腕前 | 再訪なし | 再訪あり（気にしない） | 再訪あり（決裂を追う） | 挑戦 | 和解 |
|:---|---:|---:|---:|---:|---:|
| 名手 | 100% | 100% | 100% | 0.0回 | 0.0回 |
| 上手 | 79% | 79% | 80% | 0.6回 | 0.4回 |
| 普通 | 15% | 15% | 15% | 3.0回 | 0.7回 |
| 初心 | 0% | 0% | 1% | 6.3回 | 0.4回 |

**難易度はほぼ動かない（0〜+1pt）**。挑戦回数だけが増える。
3枚一致を要求するので、和解できるのは挑戦の 1/4 ほど。救済にはならず、
「取り返す道はあるが、取り返すには読み切る必要がある」という位置に収まっている。

なお自動プレイは再訪の札を必ず取る設定にしてあるが、実際の画面には
「判定は一段重い」と明記してあり、枠が増えるだけなので見送るのは自由である。

**保存コードは変えていない**。再訪かどうかは `st.banned` に相手が居るかで決まるので、
行動の欄を増やす必要がなかった。

### R. 転向の失敗理由が、画面と食い違っていた

**報告された症状**: 転向を選び、肚を割るを選び、出てきた1枚の札を選び、
それが刺さったのに失敗した。

**判定そのものは仕様どおり**だった。肚を割るは「相手を読み切った前提の賭け」なので
型を読み違えれば一段下がる（2-7 G）。転向は満点でしか通らない（2-7 A）。
この二つが重なると、**置いた札が刺さっていても必ず失敗する**。

**本当の不具合は表示のほうにあった**。3か所が枚数を3枚と決め打ちしていた。

| 画面 | 直す前 | 実際 |
|:---|:---|:---|
| 論証を組む | 「転向は3枚すべて刺さらねば通りません。」 | 肚を割るで置くのは1枚 |
| 立場を決める | 「3枚すべて刺さらねば通らない全か無かの賭け」 | 同上 |
| 結果 | 「2枚では相手は動きませんでした」 | 置いたのは1枚で、しかも刺さっていた |

結果画面は、**置いた枚数も、失敗の理由も、両方間違っていた**。

**直したこと**:

- 枚数は `nCards` から出す。「満点」という言い方に統一し、枚数は働きかけごとに言う。
- 結果画面は、置いた札がすべて刺さっていた場合とそうでない場合を分けて説明する。
  すべて刺さっていたなら、下がった理由（読み違え・警戒・決裂の噂・再訪）を名指しする。
  さらに、その一致で支持なら通っていた場合にだけ「支持であれば通っていました」と言う
  （二段下がっていれば支持でも通らないので、その場合は言わない）。
- 論証を組む画面で、**組む前に**満点の枚数と、読み違え・警戒・再訪による下げを警告する。
- 働きかけを選ぶ画面で、転向のときだけ金品・肚を割るに
  「読み違えれば、札が刺さっても転向は通らない」と添える。

**判定の規則は変えていない**。相手の型は対話と探りで読むもので、
それを外したまま転向まで狙えば通らない、という設計は保っている。
変えたのは、何が起きたのかを画面が正しく言うようにしたことだけである。

### S. 「型」という語を使うのをやめ、働きかけの規則を画面に出す

**報告された症状**: R を直した直後、同じ人から
「腹を割ること自体が間違えた選択だったのか」「型とか言われてもなんのことやら」。

**これはこちらの落ち度だった**。`approachOf` が返すもの＝「その人物に響く当たり方」を、
画面では**「型」**と呼んでいた。この語はコード内の呼び名で、ゲーム中に一度も説明していない。

さらに悪いことに、**その規則そのものが画面のどこにも出ていなかった**。

- 6つの利益（名誉・武名／金銭・利権／安全・保身／大義・理念／力・武備／知・学問）と
  4つの働きかけの対応表（`APPROACH_BY_MOTIVE`）は、コード内にしかない。
- 利益の名前（「知・学問」など）は、練習モードと**結果画面（＝手を打った後）**にしか出ない。
  決めるときに見えるのはカードの文面だけで、それがどの利益なのかは分からない。
- つまりプレイヤーは、**規則も語彙も知らされないまま**「読み違えると一段下がる」罰を受けていた。

報告された局面（ジョン万次郎に 転向＋肚を割る）を全通り測ると：

| | 論じる | 肚を割る |
|:---|:---|:---|
| 支持 | 大成功（+5） | 成功（+2） |
| 転向 | 大成功（+5） | **失敗（0）** |

万次郎が欲しているのは〔知・学問〕で、響くのは論じる。

**直したこと**（判定の規則は変えていない）:

- 「型」という語を画面から全廃し、「相手が何を欲しているか」と言い換えた。

- 対話で問うた返答に、**それが何だったのか**を添えるようにした

- 利益を聞き出している場合、早見表の該当行に ◎ を付け、
  「筋どおりなら論じるが響きます（そう見えて違う者もいます）」と添える。
  **印は聞き出した内容からの推定であって、正解の開示ではない**。
  例外29名では推定が外れる ― その手掛かりは【情勢】の描写に残してある。

早見表は人物ごとの情報ではなく規則そのものなので、出しても謎解きは減らない。
減るのは「隠された対応表を何局もかけて当てる」作業だけである。

### T. 崖をならし、札に動機名を出す

**報告された症状**: 「選択肢がヒントと噛み合ってない感じするんだよね。
噛み合わせたら絶対あたるんだけどさぁ」

**二つの問題が重なっていた。**

**(1) 札が動機を裏切っていた。** 例：西郷（雄藩）の〔大義・理念〕は
「有能なる者が国を動かす。それが筋にございましょう」。
一方で問うたときの返答は「事を成すことよ。身の一つなど、大義の前では軽いものだ」。
「大義」と言われてこの札を選べる者はいない。

**(2) 難易度が坂ではなく崖だった。** 1面会で確実に当てられる枠数と到達率：

| 確実に分かる枠数 | 到達率 |
|:---|---:|
| 0枠 | 1% |
| 1枠 | **29%** |
| 2枠 | **93%** |
| 3枠 | 100% |

**1枠と2枠のあいだに中間がない。** だから札が読めなければ1%側に落ち、
読めるようにすれば93%側へ飛ぶ。報告者の言う「噛み合ってない」と「絶対あたる」の
あいだに、遊べる幅が存在していなかった。**札を書き直すだけでは崖の向こうへ移るだけ**で、
問題は解けない。

原因は配点にあった。支持で1枚しか刺さらないとき獲得は0。1枠しか読めない打ち手は
**4割強のターンが完全な空振り**になる。

**規則の追加 ―「手応え」**:

- 支持で1枚一致 → 時勢が **1** 動く（従来は0）。
- 手応えは**常にちょうど1**。ランク補正・響いた加算・和解の倍取りは乗らない。
- **人脈には加わらない。約束も残らない。和解もしない**（相手は動いていない）。
- 大物を動かせなかった代償（上級−1／伝説−3）は**そのまま払う**。
  ここを免除すると、伝説級への当てずっぽうが −3 から +1 に変わってしまう。
- 転向に手応えはない（全か無かのまま）。

| 確実に分かる枠数 | 手応えなし | 手応えあり |
|:---|---:|---:|
| 0枠 | 1% | 1% |
| 1枠 | **29%** | **40%** |
| 2枠 | 93% | 92% |
| 3枠 | 100% | 100% |

**上は動かない。** 埋まるのは中間だけである。

なお、手応えでも人脈に加わる案（到達率41%）とランク補正も乗せる案（45%）も測ったが、
前者は人脈が平均6.6→9.7名に膨れて 2-7 O の「縁」を薄めるため却下した。
後者は +5pt のために「手応えは常に1」という単純さを失うので採らなかった。

**表示の変更 ― 札に動機名を出す**:

```
〔知・学問〕有職故実に通じた者こそ、次の世の礎となりましょう
〔大義・理念〕万世一系の御稜威を仰ぐ。それ以上の大義がありましょうか
〔名誉・武名〕この一挙、朝廷の記録に貴殿の名が残りましょう
```

問いが「どの文がどの動機を指すか」から「**この人物は何を欲しているか**」に移る。
前者は文章の解読で、外したときに理不尽に感じる。後者は人物を読む問いで、
【情勢】の描写・開口一番・余話・対話がすべて手掛かりとして働く。
札の文面は謎かけをやめ、**実際に口にする台詞**に専念できる。

**文面の修正**: 当初キーワード判定で「読みにくい札」を26枚と数えたが、
**この数え方が誤っていた**（西郷の例は「筋」を含むため素通りし、
逆に「宮中に列なれば、いかなる嵐も御簾の内までは届きますまい」のように

### U. 台詞を相手と盤面で書き分ける

**報告された症状**: 「セリフのバリエーションがあまりに少なく、空気読めてないセリフの
羅列が臨場感のなさにつながっている」「なんで全く違う場面で違う相手を説得するのに、
おんなじセリフから選ばされてんの」

**実数を数えたところ、指摘は正確だった。**

| 要素 | 直す前 | 個別か共有か |
|:---|---:|:---|
| 開口一番 | 151行 | 人物ごと |
| 情勢の描写 | 151行 | 人物ごと |
| **問いへの返答** | **18行** | **151人で共有** |
| **論証カード** | **90枚** | **全人物・全場面で共有** |
| 雑談 | 5行 | 勢力ごと |

西郷に望みを問うたときの返答を、**他に31名が一字一句同じに言っていた**。
孝明天皇も、新選組の隊士も、大坂の豪商も。**盤面を参照する台詞は一つもなかった。**

**三つの軸を足した。**

**(1) 語り口（誰が喋るか）** ― 7つ。志士・浪士 / 武家・幕臣 / 公家・宮中 /
町人・商人 / 女 / 学者・僧 / 異人・通詞。151名を漏れなく重複なく割り当ててある。
返答は 3カテゴリ × 6動機 × **7語り口 = 126行**。

**(2) 盤面を読む一言（いま何が起きているか）** ― 12条件。
再訪・悪評・紹介・警戒・短気・時期尚早・荒事の場・幕間後・終盤・時勢高・顔が売れた・序盤。
上から順に見て当たった一つを、開口一番に継ぐ。語り口は荒い／硬い／丁寧の3系統に束ねた
（7語り口 × 12条件は書き切れないため）。

**(3) 相手の立場（誰に向かって言うか）** ― 3つ。
上（朝廷・幕閣・大名／実プレイの22%）、中（藩士・志士・学者／64%）、
下と外（町人・女・異人／14%）。`voiceOf` と `rankOfId` から導く。
**論証カードを 90枚 → 270枚に書き分けた。**

| 〔開国〕×〔利益提示〕×〔金銭・利権〕 | 文面 |
|:---|:---|
| 上 | 運上金は御公儀の金蔵をそのまま潤しまする。何年ぶんにもなりましょう |
| 中 | たった一度の交易で、藩の借財など塵芥にございます |
| 下と外 | 一度の船荷で、蔵がひとつ建ちまする。それが交易にございます |

**加えて枕（切り出し方）** ― 相手の身分ごと（7 × 3カテゴリ = 21）と、
張り詰めた盤面ごと（7条件 × 3 = 21）。論証はこの枕と核で組む。

**実測**

| | 直す前 | 直した後 |
|:---|---:|---:|
| 問いへの返答 | 18行 | 126行 |
| 論証カード | 90枚 | 270枚（すべて別の文） |
| 1局9.5人のうち返答が重なる組数 | 5.50 | 3.22 |
| 論証の異なり（400局） | 111通り | 226通り |

**残っている限界**: 1局で目にする札は86枚で、そのうち異なりは50枚。
同じ文を二度見る回数は35.8回/局ある。これは一つの勢力を押し続ければ
その勢力の札（3カテゴリ × 6動機 × 3立場 = 54枚）から86枚ぶん引くことになるためで、
鳩の巣算からくる下限に近い。**同じ主張を10人に繰り返すこと自体は設計どおり**であり、
消えたのは「違う相手に同じ文を言う」ほうである。
これ以上減らすには、時代や場をもう一軸足して札を4倍（1080枚）にする必要がある。

**保存コードは変えていない**。札の文面が変われば論証の字数と次の基点IDが動くが、
`resolve` は記録された `charId` を直接使うので再生の結果は一致する。
ただし smoke の2周目が使う「決裂を確実に起こす seed」は札の字数に依存するので、
seed 1 → 6 に取り直した（この種の固定資産は札を書き換えるたびに再取得が要る）。

### V. 台詞の性別・語り口の洗い出し

**報告された症状**: お龍（女）を人脈に持った状態で縁のある相手に会うと、
「**お龍とは長い付き合いでな。あの男が寄越したのなら、断る法がない**」と言う。
さらに「── **あの男**の紹介だ。嘘は言うまい」。

**原因**: 語り口（U）を入れたのは「喋る側」だけで、
**台詞が指す第三者**と、**共有台詞の調子**を直していなかった。

名簿の女性は5名（茶屋の芸妓・大奥の元女中・お龍・和宮・篤姫）で、
このいずれもが紹介者・決裂相手・再訪者になりうる。

**全文を機械で洗い出した結果**（24件の疑い）:

| 語 | 件数 | 判定 |
|:---|---:|:---|
| あの男／この男 | 2 | **不具合**。紹介者と立ち合い相手を指す |
| 貴殿 | 10 | 安全。すべて立場1（中）の札で、女は立場2にしか入らない |
| 彼 | 8 | 安全。「彼我」の複合語と、グラバー個人の後日談 |
| そなた／お前さん | 4 | 安全。指しているのは相手ではなく**プレイヤー** |

さらに、共有台詞そのものが**荒い男の調子で固定**されていた。
再訪の一言「刀の鯉口を切る音」「忘れておらんぞ」を、和宮が言うことになる。

**直したこと**:

- 調子を **3系統 → 4系統**に増やした（荒い／硬い／**くだけた**／丁寧）。
  以前は町人と志士が同じ「荒い」に入っていたため、女を分けても町人が荒いままだった。
  `TONE_OF_VOICE = [0,1,1,2,3,1,3]`。
- 共有台詞をすべて4系統ぶんに書き分けた ―
  縁の一言（紹介6 × 4、悪評4 × 4）、再訪の一言（5 × 4）、
  盤面の一言（12 × 4）、世間話（5勢力 × 4）。
- 第三者を指す語から性別を外した（「あの男」→「あの方」）。

**検査を常設した**。誰にでも当たりうる台詞（縁・再訪・盤面・世間話）に
`あの男|この男|その男|男が|野郎|奴が|奴の` が現れないことを verify で検査する。
あわせて次の不変条件も検査する:

- 女5名は語り口4（女）・調子3（丁寧）・立場2（下と外）に必ず入る
- 立場2の札に「貴殿」「御仁」を使わない
- 短気な者に女はいない（立ち合いの文が男を想定した書き方のままのため）

最後の一つは**回避であって解決ではない**。立ち合いの文（3通り × 勝敗）を
女の調子でも書けば制約を外せるが、いまは短気25名に女がいないことを
テストで固定して先送りしてある。

### W. 人物の絵を、あとから差し込める形にする

**問い**: 「人物の絵は？」

**現状**: 岩倉具視・近藤勇・勝海舟・西郷隆盛・徳川慶喜・木戸孝允・吉田松陰・坂本龍馬の

- 名簿と実ファイルの食い違い（実体のないID／名簿に無いファイル）は verify で落とす。

**優先順位の根拠**（500局の自動プレイで、面会相手の位を実測）

| 位 | 名簿 | 面会で当たる割合 | ここまで描いたときの被覆 |
|:---|---:|---:|---:|

| 中級 | 60名 | 32% | 77% |
| 初級 | 30名 | 23% | 100% |

**肖像の扱い**: 151名のうち95名が実在人物（上級・伝説61名と、初級・中級に混じる34名 ―
近藤勇・桂小五郎・沖田総司・福沢諭吉ら）。残る56名は「茶屋の芸妓」「脱藩した若者」のような

### X. 整理（追加をやめ、画面と例外を減らす）

**報告された批評**: 「足し算が進みすぎて、核の『人物を読み、言葉で歴史を動かす』が
少し埋もれ始めている」。削る候補として 立ち合い／再訪／世間話／常時表示のseed・保存コード、
統合案として 対話＋探る、場選択＋人物候補。

**測って確かめた**。一交渉で通る画面は6枚、判定・獲得を動かす条件は12種類あった。
批評の診断は正しい。ただし削除対象の優先順位は一部違った。

| 腕前 | 立ち合い/局 | 再訪の札/局 |
|:---|---:|---:|
| 名手 | 0.00 | 0.00 |
| 上手 | 0.20 | 0.59 |
| 普通 | 0.72 | **1.71** |
| 初心 | 1.41 | **2.78** |

批評は再訪を「遭遇が少ない」としていたが、それは名手の数字である。
**普通の打ち手には毎局1〜2回出る**。うまく打てない人ほど盤面が痩せる、という
問題への対処なので、削ると元に戻る。削るべきは遭遇ではなく規則の数。

**実施した整理（1〜5）**

| # | 内容 | 効果 |
|:---|:---|:---|
| 1 | 保存コード・seedを畳む | 面会・行き先画面から撤去。結果画面は details に。ヘッダーの seed 廃止 |
| 2 | 世間話を開口一番へ吸収 | 対話チップ 5個 → 3個。時勢観はクリックなしで出る |

**判定・代償・回数制限は1〜5のいずれでも変えていない。**

**5の途中で見つかった不具合**: 枕（切り出し方）をカテゴリごとに置いていたため、
一つの論証に「手短に申す。……長くは話せぬ。要点だけ申す。……一言で申す。」と
**同じ趣旨が三度**現れていた。立ち合い画面に論証を残すようにして初めて目に見えた。
枕は論証の頭に一度だけ置くよう直し、7身分 × 3カテゴリ = 21行 を 7行に減らした

**6: 再訪の規則を4つから2つへ**

批評の「説明量の割に」は当たっていた。再訪は〈一段重い／紹介でも消えない／通れば倍／
出現停止が解ける〉と4つの規則を一度に出していた。

当初は「倍取りを落とす」つもりで測ったが、**それは逆だった**。

| 打ち手（決裂を追う） | A: 一段重い＋倍（元） | B: 倍取りなし | C: どちらもなし |
|:---|---:|---:|---:|
| 上手 | 82%（和解0.4） | 78%（和解0.4） | **83%（和解0.4）** |
| 普通 | 19%（和解0.6） | 14%（和解0.7） | **22%（和解1.0）** |
| 初心 | 1%（和解0.4） | 0%（和解0.4） | 1%（**和解1.1**） |

倍取りは飾りではなく、一段重い判定と釣り合いを取っていた。片方だけ外すと
再訪が罠になる（B）。**両方外すと（C）、規則は半分、難易度はほぼ同じ、
和解の成立回数はむしろ増える。**

採ったのは C。残った規則は2つだけ:

- 決裂させた相手は、荒事の場でだけ向こうから来る
- 説き伏せれば和解し、出現停止が解けて人脈に加わる

判定の上下も特別な報酬もない。取るか取らないかの判断は、
「この相手に1ターン使う価値があるか」と「悪評を放置する損」だけで決まる。

**7: 幕間を二度にする（第5ターンに前編を置く）**

批評の「空いた後半へルート別ストーリーを入れる」に対応する。新しい規則は足さず、
すでにある幕間の仕組みをもう一度使う。

- `INTERLUDE_TURNS = [5, 8]`、`INTERLUDE_SETS = [前編, 後編]`。判定の仕組みは同じ
- 前編10件（和親条約の調印／将軍継嗣／安政の大獄／桜田門外／開港場の選定／
  薩英戦争の後始末／生麦の一件／長州征討の軍議／池田屋／薩長の密議）。
  いずれも後編より前に起きた出来事から採った
- **後編の冒頭が前編の選択を参照する**。「あの『和親条約の調印』で、あなたは
  二港だけ開いた。その余波は、まだ収まっていない」
- `st.interludes` に配列で持ち、`st.interlude` は直近のものを指す（盤面の一言が参照する）

**保存コードは互換を保った**。二度ぶんは `#a.b`、点のない `#a` は幕間が一度だけだった頃の
コードなので、その一度を**後半の枠**に入れて読む。旧コードはそのまま再現できる。

**増減の設計**: 最初は素直に書いたところ、前編の増減の合計が平均 +2.67 になり、
普通の打ち手が 19% → 28% に跳ねた。前編は「どちらへ傾くか」を決める場であって
点を配る場ではないので、**すべての選択肢の合計をゼロ**にし、振れ幅を ±3 に収めた。

| 腕前 | 幕間1回（第8のみ） | 幕間2回（±3・合計0） |
|:---|---:|---:|
| 名手 | 100% | 100% |
| 上手 | 86% | 86% |
| **普通** | **18%** | **24%** |
| 初心 | 1% | 1% |

**上位は動かず、普通だけが +6**。合計ゼロでもなお易しくなるのは、選択肢の中に
自分の狙う勢力を押す型が必ず一つあるためで、これは幕間という仕組みそのものの性質である。
2-7 J の「手応え」と同じく、中間だけが埋まる形なので採った。

**検査**: 幕間が第5・第8で一度ずつ起きること、同じ回が二度起きないこと、
前編と後編で鍵が一致し事件名が重複しないこと、保存コードが `#a.b` で往復すること、
点なしの旧コードが後半の枠に入ること、そして**本文に英単語が混じっていないこと**を固定した
（前編を書く過程で `returned` が一語紛れ込み、`scene` だけ直して `res` を見落としていた）。

### Y. 周回の障害を減らす（旅程・勝ち筋・主要人物）

最後まで遊んだプレイテストから、①同じ操作の反復、②30点が遠い、③一勢力集中以外の勝ち方が見えない、

## 3. 実装したルール（原作準拠）

### 3-1. 時勢と時代ランク

5勢力（公武・開国・佐幕・雄藩・抗戦）。各 **初期値0 / 上限40 / 単独覇権ライン30**。
複合革命は上位2勢力の合計28、かつ両方10以上（2-7 F）。

合計値（時代のうねり）でフェーズが決まる。

| 時代ランク | 合計 | 出現するID |
|:---|:---|:---|
| 初級期 | 0〜9 | 01〜30 |
| 中級期 | 10〜24 | 01〜90 |
| 上級期 | 25〜39 | 01〜135 |
| 伝説期 | 40〜 | 01〜151 |

なお**伝説期にはほぼ到達しない**。一勢力に寄せると、合計40に届くのとその勢力が上限40に
達してゲームが終わるのがほぼ同時になるためである。したがって伝説級16名は、事実上
**紹介枠でしか会えない希少枠**として機能する。原作の「人脈を使えばまだ時代に出てこない
大物を呼べる」という設計をそのまま体現しているので、意図的にこのままにしてある。

### 3-2. 人物選出

1. 基点ID = `(直前の論証文の文字数 × ターン数)` の下2桁（00は100）
2. 候補 = 基点ID / 基点ID+37 / 基点ID+73（151超は −151）
3. **ランク補正**: 算出IDが現在の時代ランクより高い場合 `(元のID % 30) + 1` で初級IDへ強制変換
4. 重複・既獲得・決裂済みに当たった場合は、その時代で解禁済みのID範囲内を前方へ送る

通常候補は3名。ただし `travelFatigue(lastPlace, nextPlace)` が真、すなわち京・江戸・長崎の
異なる都市圏を直行した日だけ2名になる。夜の街道は中継地としてどの都市との往来でも疲れない。

**紹介枠**は人脈リストが空なら**必ず出さない**（原作の厳守事項）。人脈がある場合のみ、
① 未獲得 ② 史実の結びつき ③ より高ランク の優先順で1名。ランク制限はかからないため、
初級期に伝説級が現れうる（＝時期尚早になる）。

### 3-3. 判定とポイント変動

各カテゴリ**3枚**の候補から1枚ずつ選ぶ（2-7 G）。

| 一致数 | 肯定（支持） | 転向狙い |
|:---|:---|:---|
| 3枚 | 相手属性 +4 | 主張属性 +4 / 相手属性 −2 |
| 2枚 | 相手属性 +2 | **通らない**（2-7 A） |
| 1枚 | 変動なし | 変動なし |
| 0枚 | 出現停止＋縁筋が閉じる | 出現停止＋縁筋が閉じる |

※ 警戒されている場合、一致数は判定前に1段下がる（2-7 B）。
※ 探った交渉は、成功しても獲得が1下がる（2-7 G）。

**ランク別補正**（時代が追いついている場合のみ）

| ランク | 成功値 | 失敗時 |
|:---|:---|:---|
| 初級 | 補正なし（+4 / +2） | なし |
| 中級 | +1（+5 / +3） | なし |
| 上級 | +2（+6 / +4） | 時勢 −1 |
| 伝説 | 2倍（+8 / +4） | 時勢 −3 |

**時代整合性リミット**: 相手のランクが現在の時代ランクより高い場合、ランク別補正は
無効化され、初級相当の基本値（+4 / +2）のみが適用される。失敗ペナルティも無効。

### 3-4. 終了とエンディング

最終ターン（10）終了時、またはいずれかの時勢が40に達した時点で終了。優先順①→②→③。

- **①単独覇権**（いずれか1つが30以上、最大値を採用）
  佐幕『徳川の再臨』/ 雄藩『諸侯の連邦』/ 開国『東洋の貿易都市』/ 公武『王政の千年王国』/ 抗戦『修羅の国』
- **②複合革命**（上位2つの合計が28以上、かつ両方10以上）
  公武+佐幕『立憲君主幕府』/ 開国+雄藩『明治維新（史実改）』/ 抗戦+開国『武装共和国』/ その他『野合の衆』
- **③混沌** — 『歴史の藻屑』

※ ①は②より先に判定する。30に到達した一勢力があれば単独覇権が優先される（2-7 F）。

## 4. 仕様の穴に置いた既定値

原作プロンプトで一意に定まらなかった箇所と、本実装が採った解釈。いずれもテーブル定数
なので、変えたい場合は `index.html` の該当箇所の数値だけ書き換えればよい。

| 論点 | 採った解釈 |
|:---|:---|
| ランク補正「+1 / +2」の適用先 | 大成功・成功の**両方**に適用 |
| 伝説の「2倍」 | 基本値の2倍（大成功 +8 / 成功 +4）。中級・上級の加算は乗らない |
| 上級・伝説の「失敗時 時勢−N」 | **失敗(1点)と決裂(0点)の両方**に適用。肯定なら相手属性、転向なら主張属性から引く |
| 時勢値の下限・上限 | 0〜40 でクリップ。転向で相手属性を減らしても負にならない |
| 決裂した人物 | 以後の抽選から**永久**に除外 |
| 獲得済み（人脈）人物 | 通常枠には再登場しない。紹介枠の抽選母集団としては使われ続ける |
| 人脈の消費 | **消費されない** |
| 転向時の「主張属性」 | プレイヤーが相手の属性以外の4つから明示的に選ぶ |
| 複数属性（ID100 坂本龍馬 [開雄]） | 面会時にどちらの属性に向き合うかを先に選ぶ。増減はその属性のみ |
| 「史実の結びつき」 | 126件の関係テーブル（`TIES`）を双方向グラフとして扱う。縁が尽きた場合は同勢力の未獲得から |
| 紹介枠の「より高ランク」 | 絶対優先ではなく重み（初級1・中級4・上級9・伝説16）付き抽選。理由は 2-6 |
| 基点IDの法 | 名簿数151（素数）。理由は 2-3 |
| 第1ターンの基点ID | 直前の入力が存在しないため seed から導出 |
| 対立の閾値 | 時勢12以上で対立勢力の人物が警戒（`WARY_LINE`）。実測で決定、理由は 2-7 B |
| 複合エンドの合計ライン | 28（`COMBO_GOAL`）。単独30は高難度として維持 |
| 複合エンドの二番目の下限 | 10（`COMBO_MIN`） |
| 遠路直行の代償 | 通常面会候補3名→2名。得点・ターン・人脈枠は減らさない |
| 候補カードの枚数 | 各カテゴリ3枚 |
| 探りの上限 | 1局4回（`PROBE_LIMIT`）。掃引で決定、理由は 2-7 G |
| 同ランク・同値の並び順 | 小さいIDを優先（決定論のため） |

## 5. 名簿の使われ方（2000局の自動プレイ実測）

| 指標 | 100名時代 | 151名・改修後 |
|:---|---:|---:|
| 1局に登場する異なり人数 | 28.1名 | **30.7名** |
| 1000局で一度でも登場 | 95 / 100 | **151 / 151** |
| 一度も登場しない人物 | 5名 | **0名** |
| 紹介枠の異なり人数 | 33名 | **142名** |

## 6. 難易度
