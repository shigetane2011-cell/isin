# 主要人物の創作彩色肖像

ゲーム内の肖像は、史料画像の顔立ちを参照して新たに制作した創作彩色画です。
史料写真そのもののカラー化ではなく、史実上の服色を断定するものでもありません。

| ゲーム内人物 | ファイル | 参照した肖像史料 |
|:---|:---|:---|
| 岩倉具視 | `iwakura-tomomi.webp` | 国立国会図書館「[近代日本人の肖像](https://www.ndl.go.jp/portrait/datas/23/)」 |
| 近藤勇 | `kondo-isami.webp` | 国立国会図書館「[近代日本人の肖像](https://www.ndl.go.jp/portrait/datas/269/)」 |
| 勝海舟 | `katsu-kaishu.webp` | 国立国会図書館「[近代日本人の肖像](https://www.ndl.go.jp/portrait/datas/51/)」 |
| 西郷隆盛 | `saigo-takamori.webp` | 国立国会図書館「[近代日本人の肖像](https://www.ndl.go.jp/portrait/datas/85/)」掲載のキヨッソーネ肖像 |
| 徳川慶喜 | `tokugawa-yoshinobu.webp` | 国立国会図書館「[近代日本人の肖像](https://www.ndl.go.jp/portrait/datas/147/)」 |

| 坂本龍馬 | `sakamoto-ryoma.webp` | 文化遺産オンライン「[坂本龍馬湿板写真](https://online.bunka.go.jp/heritages/detail/47451)」 |

西郷隆盛は、本人と確定した写真が現存していません。本作では一般に知られる
エドアルド・キヨッソーネ作の肖像を「見慣れた西郷像」の基準として参照しています。

国立国会図書館「近代日本人の肖像」の掲載画像は、同館の
[ご利用について](https://www.ndl.go.jp/portrait/about/) により著作権保護期間満了と案内されています。
